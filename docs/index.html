Los datos

La base de datos es propia: un registro de cada libro leído con las siguientes variables.

  • titulo, autor, editorial — texto
  • genero — 6 categorías (suspenso y policial, novela, desarrollo personal, etc.)
  • tipo — ficción / no ficción
  • pais_autor, idioma_original — geográficas
  • genero_autor — mujer / hombre
  • anio_publicacion, decada — temporales
  • paginas — numérica
  • calificacion — numérica (1 a 5)
  • formato — papel / digital
  • estado — leído, leyendo, por leer, abandonado

Fuente: exportación de mi biblioteca de Goodreads 28 libros en total, de los cuales 20 leídos (7.335 páginas). Descargar el dataset (CSV)
